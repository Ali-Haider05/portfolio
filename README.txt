ALI HAIDER PORTFOLIO REDESIGN

1. Open index.html in a browser to preview.
2. To deploy, upload index.html, styles.css, script.js, and the assets folder together to your portfolio hosting directory.
3. Back up your existing portfolio before replacing files.
4. Keep assets/id.png and assets/right_pointing.png in the assets directory.
5. GitHub and LinkedIn links are configured. SmartDoc has no repository link yet, so none was invented.
6. Fonts use Google Fonts; the site falls back to system fonts offline.

This is a standalone static HTML/CSS/JS version, not a patch to your existing source files.
